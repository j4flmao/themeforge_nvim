# Community presets

These are small, copyable ThemeForge configurations. Put one in your Neovim
config or recreate it with the matching profile/blend.

| Preset | Intent |
|---|---|
| `focus.lua` | Quiet, low-distraction editing |
| `high-contrast.lua` | Strong text and UI separation |
| `monochrome.lua` | Restrained grayscale palette |

Community contributions are welcome. Keep presets short, explain the intent,
and include a screenshot when the change is visual.
